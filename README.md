# Algorithmic Universe Web

Публічна браузерна лабораторія проєкту **Algorithmic Universe**.

Основне дослідницьке та Python-ядро зберігається в окремому приватному репозиторії. Цей репозиторій містить лише клієнтську вебверсію для тестування симуляцій у браузері.

Після ввімкнення GitHub Pages лабораторія буде доступна за адресою:

https://llcdeliveryimport-glitch.github.io/algorithmic-universe-web/
